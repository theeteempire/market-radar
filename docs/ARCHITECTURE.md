# البنية التقنية

## 1. نظرة عامة

```
                       ┌──────────────────────────────────────────┐
                       │              المتصفح (RTL)                │
                       │  index.html + styles.css + app.js         │
                       │  Chart.js (محلي) · EventSource · Audio     │
                       └───────────────┬──────────────────────────┘
                                       │  HTTP + SSE
                       ┌───────────────▼──────────────────────────┐
                       │            src/app.js                     │
                       │  HTTP server · Router · SSE hub           │
                       │  Static files · CSP · JSON API            │
                       └───┬───────────┬───────────┬──────────────┘
                           │           │           │
                  ┌────────▼──┐  ┌─────▼─────┐ ┌───▼──────────┐
                  │ MarketStore│  │AlertEngine│ │ SettingsStore │
                  │ (ذاكرة)    │  │ (قواعد)   │ │ (JSON ذرّي)   │
                  └────▲───────┘  └─────▲─────┘ └──────────────┘
                       │                │
        ┌──────────────┴────────────────┴────────────────┐
        │                  المزوّدات                      │
        │ crypto.js  yahoo.js  news.js  mastodon.js       │
        │ x.js  telegram.js                               │
        └───────┬────────┬────────┬────────┬─────────────┘
                │        │        │        │
            Binance   Yahoo   RSS/Google   X API v2
                                 │
                    ┌────────────▼────────────┐
                    │      NewsPipeline       │
                    │ translate.js + enrich.js│
                    │ (طابور أولوية مستقل)     │
```

**المبدأ:** الخادم هو المصدر الوحيد للحقيقة. المتصفح لا يتصل بأي مصدر خارجي (باستثناء خطوط Google)؛ كل شيء يمر عبر `/api/*` وSSE. هذا يمنع مشاكل CORS ويخفي أي مفاتيح.

## 2. دورة حياة الطلب

1. `server.js` يحمّل `.env` ثم يستورد `src/app.js` ديناميكيًا (بعد ضبط المتغيرات).
2. `createApp()` ينشئ المخزن، الإعدادات، محرك التنبيهات، المزوّدات، وخادم HTTP.
3. `listen()` يربط المنفذ ثم يبدأ المزوّدات (إلا إذا `DISABLE_PROVIDERS=1`).
4. كل مزوّد يعمل في حلقة مستقلة (`while (!stopped)` + `sleep`) — لا يوجد جدولة مركزية، فلا يتعطل مزوّد ببطء آخر.
5. عند وصول بيانات: `store.applyTick` / `store.addNews` تبثّ حدثًا داخليًا (`EventEmitter`).
6. مزوّد الأخبار يمرّر العناصر المضافة إلى `NewsPipeline` (ترجمة + إثراء صور) عبر `onItems`.
7. `app.js` يستمع للأحداث ويوزّعها على:
   - `AlertEngine` (تنبيهات)،
   - كل عملاء SSE المتصلين (`news_update` عند اكتمال الترجمة/الصورة).

## 3. المخزن (`src/store.js`)

كل شيء في الذاكرة. لا قاعدة بيانات.

| البنية | المحتوى | الحد |
|---|---|---|
| `assets: Map` | 24 أصلًا + السلسلة الزمنية لكل أصل | 4 ساعات / 6000 نقطة |
| `news: []` | أخبار مرتبة تنازليًا بالوقت | 800 عنصر |
| `newsKeys: Set` | عناوين مُطبَّعة لمنع التكرار | يتبع `news` |
| `urlKeys: Set` | روابط مطلقة لمنع التكرار | يتبع `news` |
| `newsById: Map` | وصول سريع للتحديث عبر SSE | يتبع `news` |
| `alerts: []` | تنبيهات مرتبة بالأحدث | 300 عنصر |
| `sources: Map` | صحة كل مصدر | 27 مصدرًا |

### تطبيع العناوين
`normalizeTitle` يزيل HTML، الترقيم، المسافات الزائدة، ويحوّل للحروف الصغيرة، ويقصّ عند 180 حرفًا. يمنع تكرار نفس الخبر من عدة خلاصات (شائع جدًا مع Google News).

### السلاسل الزمنية
- كل نقطة `{ t: epochMs, p: price }`.
- `applyTick` يضيف نقطة عند كل تحديث.
- `seedSeries` يدمج نقاطًا تاريخية (شموع Binance أو Yahoo) بمفتاح `Math.floor(t/1000)` لتجنب التكرار.
- `downsample` يقلّل للعرض (240 نقطة في اللقطة، حتى 2000 عبر `/api/series`).
- القصّ: أي نقطة أقدم من 4 ساعات تُحذف.

## 4. محرك التنبيهات (`src/alerts.js`)

### التدفق
```
tick ──► onTick ──► #checkMoves      (كل 5 ثوانٍ لكل أصل)
                ├─► #checkVolatility (كل 15 ثانية لكل أصل)
                └─► #checkThresholds (كل tick)
news ──► onNews ──► scoreNews ──► قيود المعدل/التهدئة ──► تنبيه
```

### لماذا فترات مختلفة؟
- فحص الحركة كل 5 ثوانٍ يقلّل الحساب دون فقدان أحداث مهمة (النوافذ بالدقائق).
- فحص التقلّب كل 15 ثانية كافٍ لأنه يعتمد على نوافذ 5/35 دقيقة.
- الحدود السعرية تُفحص عند كل tick لأن العبور قد يحدث في أي لحظة.

### التهدئة (Cooldowns)
مفتاح `Map` بسيط: `key → timestamp حتى`. يمنع إغراق المستخدم:
- حركة: `asset:move:window` — 8 دقائق.
- تقلّب: `asset:volatility` — 10 دقائق.
- حد سعري: `asset:threshold:above|below` — 30 دقيقة.
- خبر: `label` — 10 دقائق، بالإضافة إلى سقف 10/5د (20 للحرجة).

### تصنيف الأخبار
`HIGH_RULES` و`MEDIUM_RULES` مصفوفات Regex ثنائية اللغة (عربي/إنجليزي). الترتيب مهم:
1. أي تطابق حرج → `high`.
2. تطابقان متوسطان أو أكثر → `medium`.
3. تطابق واحد → `low`.
4. لا شيء → لا تنبيه.

هذا بسيط وقابل للتفسير، لكنه **ليس فهمًا دلاليًا**. قد يخطئ في العناوين الساخرة أو التوقعات («توقعات بانهيار») — وهي إشارة لا حكم.

### الإشعارات الخارجية
`#emit` يحفظ التنبيه أولًا (مصدر الحقيقة)، ثم يستدعي `notifier.notify` بشكل غير متزامن. فشل Telegram لا يؤثر على التنبيه المحلي.

## 5. المزوّدات

### `crypto.js`
- تهيئة: 240 شمعة دقيقة لكل أصل (تسلسليًا مع 120ms فاصل).
- حلقة: طلب واحد لكل الرموز كل ثانية.
- يعيد المحاولة بتراجع أسّي عند الفشل (حتى 30s).

### `yahoo.js`
- 18 أصلًا (6 سلع/مؤشر + 12 سهم تقنية)، طلب لكل أصل مع فاصل زمني (≈4–5 ثوانٍ للدورة).
- يتخطى التحديث إذا لم يتغير `regularMarketTime` والسعر (توفيرًا للنطاق).
- يستخرج نقاط الجلسة النظامية لحساب الافتتاح.
- تراجع حتى 5 دقائق.

### `news.js`
- حلقة مستقلة لكل خلاصة (23 حلقة).
- تأخير أولي متدرّج لتجنّب انفجار الطلبات.
- طلبات شرطية ETag/Last-Modified.
- تراجع أسّي حتى 30 دقيقة، مع تشتيت ±15% عند النجاح.
- يمرّر العناصر المضافة إلى `onItems` (خط المعالجة).

### `mastodon.js`
- 6 وسوم عامة عبر `/api/v1/timelines/tag/{tag}`.
- يستخرج الصور من `media_attachments` مباشرة.
- تراجع أسّي حتى 30 دقيقة عند 429/5xx.
- خطوط زمنية عامة فقط؛ لا مصادقة ولا كشط.

### `x.js`
- معطّل ما لم يوجد توكن.
- 4 استعلامات متسلسلة مع 1.5s فاصل.
- يعالج 429 عبر `x-rate-limit-reset`.

### `telegram.js`
- يرسل فقط التنبيهات التي تطابق `TELEGRAM_MIN_SEVERITY`.
- حد أدنى 4 ثوانٍ بين الرسائل.
- HTML escape يدوي (بدون مكتبات).

## 5.1 خط معالجة الأخبار (`src/pipeline.js`)

```
addNews ──► handle(items) ──► طابور أولوية
                                 │
                    ┌────────────┴────────────┐
                    │                         │
              translate.js              enrich.js
          (تزامن 3، 90/دقيقة)          (تزامن 3، 30/دقيقة)
                    │                         │
                    └────────► store.updateNews ──► SSE news_update
```

- **الأولوية:** الأهمية + 40 للعاجل + 8 عند غياب الصورة − 60 للعربية − تقادم زمني.
- **الترجمة:** العناوين دائمًا، والملخصات للعاجل/المهم (أو الكل حسب الإعداد). تُدمج حتى 20 نصًا في طلب واحد عبر `clients5` بعد نافذة تجميع 25ms، مع حد 90 طلبًا/دقيقة وإعادة محاولة عند 429/5xx.
- **الصور:** تُجدول بعد الترجمة **دون حجب الطابور**؛ جلب `og:image` محدود بـ30/دقيقة.
- **البدء البارد:** عند وصول مئات الأخبار، تُترجم العناوين أولًا (تزامن 6)، ثم تصل الصور تدريجيًا.
- **التحديث الفوري:** كل اكتمال ترجمة/صورة يبثّ `news_update` للواجهة.

### `src/impact.js`
- محرك قواعد ثنائي اللغة (عربي/إنجليزي) يطابق محفّزات مثل: فائدة، تضخم، أوبك، حرب، اختراق، ETF، قيود تصدير، طلب AI، أرباح، ركود.
- يعيد: الاتجاه، الثقة، الأصول المتأثرة، السبب، والأفق الزمني.
- يحدد `breaking` عند محفّز قوي أو أهمية ≥74.
- **ليس تنبؤًا ولا نصيحة استثمارية**؛ القواعد شفافة في `src/impact.js`.

## 6. خادم HTTP (`src/app.js`)

### التوجيه
Router يدوي عبر `if (pathname === ...)` — بسيط ومقروء لعدد محدود من المسارات. لا إطار عمل.

### SSE
- `Content-Type: text/event-stream`
- `retry: 3000`
- حدث `snapshot` فوري عند الاتصال، ثم أحداث تدريجية.
- نبضة `: ping` كل 15 ثانية لمنع إغلاق الوسطاء.
- تنظيف عند `close`/`error`.
- حماية من بطء العميل: إذا تجاوز `writableLength` 512KB يُتخطى الإرسال لهذا العميل.

الأحداث: `snapshot`, `tick`, `news`, `news_update`, `alert`, `source`, `settings`, `alerts_ack`.

### الملفات الثابتة
- `path.resolve(PUBLIC_DIR, '.' + pathname)` ثم التحقق من البادئة → 403 عند الخروج.
- `Cache-Control: no-cache` للتطبيق، و`immutable` لمجلد `vendor/`.
- MIME صريح.

### الأمان
- CSP صارم: `script-src 'self'`، `connect-src 'self'`، خطوط Google مسموحة فقط.
- `X-Frame-Options: SAMEORIGIN`, `nosniff`, `no-referrer`.
- حد جسم 64KB.
- **لا مصادقة** — الاعتماد على الاستماع المحلي.

## 7. الواجهة (`public/`)

### الحالة
كائن `state` واحد: خرائط للأصول والسلاسل والمصادر، ومصفوفات للأخبار والتنبيهات، ومحدّدات العرض (الفئة، المدى، البحث، التهدئة).

### التحديث
- `tick` → تحديث DOM مباشر للعنصر المتأثر فقط (وليس إعادة رسم كل القائمة).
- `news`/`news_update`/`alert` → إعادة رسم القائمة المفلترة، مع الحفاظ على موضع التمرير.
- الزمن النسبي («قبل 3 د») يُحدَّث كل ثانية دون أي طلب شبكة.
- الرسم البياني محدود بـ 850ms بين التحديثات (`chartRenderAt`) لتجنّب إرهاق Canvas.
- إعادة رسم كاملة للوحة المتابعة/الشريط كل 30 ثانية (للرسوم المصغرة).

### شريط «عاجل»
- يختار أعلى الأخبار أهمية/عاجلية، ويعرض صورة حقيقية + عنوانًا عربيًا + النص الأصلي + تقدير التأثير.
- يتبدّل تلقائيًا بعد زمن قراءة تقديري (حسب طول النص)، مع سرعات 1×/1.5×/2×/3×، وإيقاف/سابق/تالي، وشريط تقدّم.
- يعمل بعمودين على سطح المكتب وعمود واحد على الجوال.

### لوحة التقنية
- 12 سهمًا مع سعر وتغيّر ومخطط مصغّر، تُحدَّث مع دورات Yahoo.
- الضغط على أي بطاقة يعرض السهم في الرسم الكبير.

### الرسم البياني
Chart.js 4.4.7 بوضع `parsing: false` ونقاط `{x, y}`، محور x خطي بالزمن. التدرّج يُعاد إنشاؤه حسب اتجاه السعر.

### الأمان في الواجهة
- كل نص من المصادر يمر عبر `escapeHtml` قبل الإدراج.
- الروابط تمر عبر `safeUrl` (http/https فقط) و`rel="noopener noreferrer"`.
- لا `innerHTML` لبيانات غير مطهّرة.

### الصوت والإشعارات
- Web Audio (بدون ملفات صوتية) — نغمة مختلفة لكل خطورة.
- يتطلب تفاعل مستخدم أولًا (سياسة المتصفح).
- `Notification` فقط عندما يكون المستند مخفيًا.

## 9. قرارات تصميمية

| القرار | السبب |
|---|---|
| بدون npm | بيئة بلا مدير حزم؛ تقليل المخاطر وسهولة النقل |
| REST وليس WebSocket للمصادر | أبسط، يكفي لثانية واحدة، ولا يحتاج إعادة اتصال معقدة |
| SSE وليس WebSocket للواجهة | أحادي الاتجاه بطبيعته، يعيد الاتصال تلقائيًا |
| الذاكرة وليس SQLite | لا اعتماديات، والبيانات قابلة لإعادة البناء |
| Chart.js محلي | يعمل دون إنترنت للواجهة، ويتوافق مع CSP |
| تصنيف Regex | قابل للتفسير والتعديل دون نموذج أو مفتاح |
| ترجمة عبر نقطة عامة | لا مفاتيح ولا حزم؛ قابلة للتعطيل، مع تخزين مؤقت |
| إثراء صور منفصل عن الترجمة | جلب og:image بطيء ومحدود المعدل؛ فصله يمنع تجميد العناوين |
| تقدير تأثير بقواعد | شفاف وقابل للمراجعة، ولا يُقدَّم كتنبؤ |
| تراجع مستقل لكل مصدر | فشل Reddit لا يجب أن يبطئ Binance |

## 10. التوسّع

### إضافة أصل
أضف كائنًا في `ASSETS` (`src/config.js`) مع `source` مناسب. إن كان مصدرًا جديدًا، أضف مزوّدًا في `src/providers/` واربطه في `createApp`.

### إضافة خلاصة أخبار
أضف عنصرًا إلى `NEWS_FEEDS`:
```js
{ id: 'my-feed', name: 'اسم المصدر', cls: 'energy', lang: 'ar', interval: 180000, url: 'https://...' }
```
لا حاجة لتعديل أي شيء آخر.

### إضافة قاعدة تنبيه
أضف `{ label, re }` إلى `HIGH_RULES` أو `MEDIUM_RULES` في `src/alerts.js`، وأضف اختبارًا في `tests/alerts.test.js`.

### إضافة قاعدة تأثير
أضف قاعدة إلى مصفوفة القواعد في `src/impact.js` (كلمات عربية/إنجليزية، اتجاه، أصول، ثقة)، وأضف اختبارًا في `tests/impact.test.js`.

### إضافة وسم Mastodon
أضف `{ tag: 'ethereum', cls: 'crypto' }` إلى `MASTODON.tags` في `src/config.js`.

### تعطيل المعالجة
`NEWS_PIPELINE_ENABLED=0` يوقف الترجمة وإثراء الصور معًا، أو عطّل كلًّا على حدة عبر `TRANSLATE_ENABLED` و`IMAGE_ENRICH_ENABLED`.

### إضافة قناة إشعار
أنشئ كائنًا بواجهة `notify(alert)` و`status()`، ومرّره إلى `AlertEngine` في `app.js`.

## 11. الأداء والموارد

القياس الفعلي أثناء التشغيل الحي: **~100MB RSS** بعد دقائق من التشغيل مع 27 مصدرًا و24 أصلًا و~600 خبر وطابور ترجمة/صور.

- Binance: 60 طلبًا/دقيقة.
- Yahoo: 54 طلبًا/دقيقة (18 أصلًا × 3).
- الأخبار: ~8–12 طلبًا/دقيقة موزّعة.
- Mastodon: ~2 طلبًا/دقيقة (6 وسوم كل 3 دقائق).
- إثراء الصور: 30 طلبًا/دقيقة كحد أقصى.
- SSE: بث 6 ticks/ثانية كحد أقصى (حجم صغير لكل حدث).

نقاط الضغط المحتملة: سلاسل 4 ساعات لكل أصل (24 × 6000 نقطة كحد أقصى) — صغيرة جدًا في الذاكرة. القائمة الكبيرة الوحيدة هي الأخبار (800 عنصر).

## 12. ما لم يُنفَّذ

- مصادقة/مستخدمون.
- استمرارية البيانات عبر إعادة التشغيل.
- إشعارات بريد/SMS.
- تحليل مشاعر (Sentiment) حقيقي.
- WebSocket لأسعار Binance.
- اختبارات متصفح آلية ضمن `npm test` (تم التحقق البصري عبر Chrome headless وCDP على 1600×1150 و390×844).
